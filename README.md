# ⚽ Premier League Predictor

Aplikasi web prediksi skor & pemenang Premier League dengan antarmuka Bento Grid bertema terang (light theme) yang bersih dan modern.

## ✨ Fitur Utama
- **Light Theme & Bento UI**: Desain bersih, elegan, dan kontras tinggi.
- **Prediksi 1 / X / 2**: Pilih tim kandang (1), seri (X), atau tandang (2).
- **Aturan Poin Otomatis**: Tebakan tepat = +3 poin, salah = 0 poin.
- **Panel Admin Terpadu**:
  - Tentukan batas waktu (deadline) prediksi per matchweek.
  - Upload skor akhir pertandingan manual (Full Time).
  - Klasemen / Leaderboard otomatis terhitung saat skor diisi admin.
- **Responsif**: Nyaman digunakan di desktop maupun smartphone.

## 🚀 Deploy ke Vercel
Proyek ini siap dideploy langsung ke [Vercel](https://vercel.com):
1. Push repository ini ke GitHub.
2. Di dashboard Vercel, pilih **Add New Project** lalu import repository ini.
3. Klik **Deploy** (tanpa konfigurasi tambahan).
